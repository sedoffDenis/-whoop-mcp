Privacy Policy — WHOOP MCP Personal Integration

Last updated: October 7, 2026

This application is a personal, non-commercial integration used by the account owner to access and analyze their own WHOOP health and fitness data.

Data accessed

The application may access WHOOP data authorized by the account owner, including cycle/activity data, workouts, recovery, sleep, and body measurements.

How data is used

Data is used solely to provide personal health, fitness, nutrition, and activity analysis to the account owner. It is not sold or used for advertising. Data is shared only where technically necessary to provide services explicitly requested by the account owner.

Authentication

The application uses WHOOP OAuth authentication. OAuth credentials and access/refresh tokens are used only to authenticate authorized requests to the WHOOP API. The application does not request or store the user's WHOOP password.

Data retention and access

This is a personal-use application. Access to WHOOP data can be revoked by the account owner at any time through WHOOP account settings. OAuth tokens should be stored securely and must not be committed to a public source-code repository.

Contact

For questions regarding this privacy policy, please contact the application owner through the GitHub account associated with this site.
